## Needs from Sampo

Real credentials required before each milestone can run against live services (all have dev-mock fallbacks until then, per the build-gate rule — nothing here blocks the build):
- Clerk API keys (M2)
- Neon Postgres connection string (M1)
- Didit API key (M3)
- OpenAI API key — Whisper + moderation (M4, M12)
- FFMPEG_PATH (a real ffmpeg binary path for the deployment target) — for real video frame extraction ahead of moderation (M4/M12); until set, sampled frames are a fixed placeholder image, harmless today since the moderation adapter it feeds is itself still the dev-mock
- INTERNAL_REVIEWER_CLERK_IDS (M12) — who may open `/internal/moderation`; unset today, so any signed-in user can (`lib/moderation/reviewer-access.ts`'s own comment) — not a live-service credential like the others on this list, but the same "unblocks the build, needs a real value before this matters in production" shape
- Anthropic API key — date-idea generation (M10)
- Google Places API key (M9)
- Pusher Channels keys (M11)
- Resend API key + a verified from-address (M13) — RESEND_API_KEY and RESEND_FROM_EMAIL are both required (config.ts's isResendConfigured()), since Resend has no sensible default sender to fall back to
- CRON_SECRET (M13, optional) — signs the `/api/cron/chat-window-reminders` requests `apps/web/vercel.json`'s Vercel Cron entry sends; unset today, so the route accepts any request (fine for local dev, not for a public deployment) — also confirm the target Vercel plan supports a 5-minute cron interval (`apps/web/vercel.json`'s `*/5 * * * *`), since a 15-minute-lead reminder needs finer granularity than a once-daily Hobby-plan cron can give
- Confirmation that ENGINEERING_SPEC.md §13's retention defaults (30-day clip purge, 90-day chat retention) are acceptable, or the real numbers to use instead, before public launch.
